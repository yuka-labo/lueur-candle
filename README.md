# Lueur (リュール) — 世界の愛の詩を灯す

Lueur（リュール）は、キャンドルに息を吹きかけると世界の愛の詩が浮かび上がる、静かな癒やしのPWAアプリケーションです。

「灯-TOMOSHIBI-」をベースに、より普遍的な愛の言葉を届けるアプリとして生まれ変わりました。

## 特徴 - Features

- **キャンドル体験**: マイクに息を吹きかける、または画面をタップすることで、炎が揺らぎ、詩が現れます。
- **世界の愛の詩**: シェイクスピア、ルーミー、ネルーダ、日本の和歌など、時代や国を超えた約145編の愛の言葉を収録。
- **時間帯と季節**: 朝、昼、夕、深夜の時間帯と、四季（春・夏・秋・冬）に合わせて、表示される詩が変化します。
- **作者名の表示**: 詩と共に、その言葉を紡いだ作者の名前が表示されます。
- **PWA対応**: ホーム画面に追加して、アプリのように使えます。

## 技術スタック - Tech Stack

- **HTML5 / CSS3**: モダンなCSS変数とアニメーションを使用
- **JavaScript (Vanilla)**: フレームワークなしの軽量設計
- **Web Audio API**: マイク入力の検知に使用
- **Service Worker**: PWA化とオフライン対応

## 使い方 - Usage

1. アプリを開く
2. 「タップして始める」を押して、少し待つ
3. キャンドルに息を吹きかけるか、タップする
4. 炎が揺れ、詩が浮かび上がる

## 開発環境のセットアップ

```bash
# リポジトリをクローン
git clone https://github.com/yuka-labo/lueur-candle.git

# ディレクトリへ移動
cd lueur-candle

# ローカルサーバーを起動（例: npx serve）
npx serve .
```
